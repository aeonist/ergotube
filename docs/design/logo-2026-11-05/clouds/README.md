# ErgoTube — cloud logo exploration

Created on 5 November 2026 at the user's request for a cloud-based logo, following the warm cinema-sofa studies.

## Directions

1. **Cloud play** — an asymmetric soft cloud with a rounded play-shaped counter. Terracotta on vanilla. [PNG](cloud-play.png).
2. **Cloud sofa** — a cloud backrest and embracing curled arms, continuing the personal-cinema idea. Apricot on wine. [PNG](cloud-sofa.png).
3. **Cloud beam** — a cloud acting as a cinema projector, emitting a triangular beam. Olive on honey. [PNG](cloud-beam.png).

Cloud play is the recommended simple icon direction. These are exploratory concepts pending selection, rather than a change to the application's identity.

Tool: built-in image generation. [Full prompts](PROMPTS.md).

## Validation and scope

Visually reviewed all three presentations: each uses a cloud motif, the ErgoTube wordmark reads correctly, the warm palette and rounded vintage serif character remain consistent with the preceding direction, and the small emblem samples are present. All three outputs are square, 1254 × 1254 px.

These raster proposals are not production vector masters. Small-size optical correction and Android launcher packaging belong to implementation of the selected design. No application source or resources changed, so Android builds, tests and emulator checks do not apply.
